# Adediwura Afolabi — Personal AI Portfolio Website

A premium, production-grade personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**, using **Lora** as the primary editorial serif typography standard.

---

## 🎯 Positioning & Narrative

- **Identity:** AI Product Builder | AI Automation Developer | AI Solutions Builder
- **Core Triad:** Engineering Mindset · Creative Execution · AI-Powered Thinking
- **Core Message:** *"I don't just use AI tools. I build practical, deterministic systems."*
- **The Bridge:** Connecting frontline social media & audience psychology with Mechatronics systems thinking and autonomous AI workflows.

---

## 🚀 Key Sections & Features

1. **Interactive Hero**: Features the 5-stage AI workflow diagram (**Input → AI Reasoning → Automation → Action → Result**) with clickable stage inspectors.
2. **The Strategic Bridge**: Explains why frontline marketing made Adediwura a superior AI automation builder.
3. **What I Build (Capabilities)**: 6 core capability cards covering AI Automation, Voice Agents, AI Agents, AI Products, ChatGPT Solutions, and Digital Growth.
4. **Things I've Built (Featured Projects)**: Deep-dive case studies with visual execution blueprints:
   - **Marcus Vance Automotive**: Enterprise Autonomous AI Intake Agent (CRM Ticket First, Sensitivity Quarantine, Deterministic Pricing).
   - **GText Homes**: Autonomous Real Estate Voice Agent (Twilio, ElevenLabs, Sub-second Telephony).
   - **The Visionary Nation**: Community Operations & Birthday Engine (Multi-sheet deduplication, 234 phone normalization, 7 PM WAT digest).
   - **Digital Growth Track Record**: Ovie's Kitchen (250+ online orders, 2,000 accounts reached) & Flowery Nectar Honey (On-page SEO).
5. **Interactive System Simulator**: Live browser playground where prospective clients can test automation flows (Standard Quote, Sensitivity Quarantine, Luxury Real Estate Voice Call).
6. **Career Evolution**: 6-phase chronological timeline from Social Media to AI Products.
7. **The Engineering Side**: Mechatronics Engineering foundations, CAD modeling in SolidWorks, MATLAB, and robotics.
8. **Methodology (How I Work)**: 5-step engineering process (Understand → Map → Design → Build → Improve).
9. **Technology Stack**: Verified, honest categorization across AI, Automation, Voice, CRMs, Creative, and Engineering.
10. **Interactive Consultation & Contact**: 1-click email copy, LinkedIn link, and interactive service-scoping form.

## 🛠️ Local Development & Deployment

### Run Locally (Dev Server):
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Build for Production:
```bash
npm run build
```
Generates optimized, minified static assets in `dist/`.

### Preview Production Build:
```bash
npm run preview
```

### 1-Click Deployment:
The static output in `dist/` can be deployed immediately to:
- **Vercel**: Run `npx vercel`
- **Netlify**: Drag & drop the `dist/` folder
- **GitHub Pages**: Deploy `dist/` via `gh-pages`
- **Cloudflare Pages**: Connect repo and set build output to `dist`
